# Konsep Portfolio Programmer

## Tujuan

Saya ingin membangun portfolio sebagai programmer untuk memperkenalkan kemampuan saya kepada startup yang membutuhkan developer berbakat dan mampu menyelesaikan berbagai permasalahan pada sistem mereka.

Portfolio ini diharapkan dapat menampilkan pengalaman, teknologi yang dikuasai, serta project dan kompetisi yang pernah saya ikuti secara profesional dan mudah dipahami.

## Konsep Halaman

Saat user membuka portfolio, halaman pertama akan menampilkan:

- Foto saya.
- Nama saya sebagai fokus utama halaman.

Saat user melakukan scroll, halaman akan menampilkan beberapa section berikut secara berurutan.

### 1. Pengenalan

Section ini berisi deskripsi singkat tentang diri saya, keahlian, dan fokus saya sebagai programmer.

### 2. Teknologi yang Digunakan

- Python
- PHP
- MySQL
- PostgreSQL
- MongoDB
- React
- JavaScript

**Teknologi AI:**

- OpenCode
- Claude
- GitHub Copilot
- Gemini

### 3. Project dan Kompetisi

- Daftar project yang pernah dikerjakan.
- Daftar lomba atau kompetisi yang pernah diikuti.
- Informasi pendukung, seperti deskripsi, teknologi yang digunakan, link demo, dan link repository jika tersedia.

### 4. Footer

- Informasi kontak.
- Link media sosial atau platform profesional.
- Link repository atau informasi umum lainnya.

## Sistem Admin

Section **Teknologi yang Digunakan** dan **Project dan Kompetisi** perlu dilengkapi dengan sistem admin. Melalui sistem ini, saya dapat menambahkan, mengubah, dan menghapus data terbaru tanpa harus mengubah kode secara langsung.

## Pembagian Pengerjaan

- **Claude:** mengerjakan backend dan logic aplikasi.
- **OpenCode:** mengerjakan UI/UX dan tampilan frontend.

## Struktur Project dan Deployment

- **Frontend:** dikerjakan di `D:\Petra-Portfolio`.
- **Backend:** dikerjakan di `D:\Petra-Portfolio-Backend`.
- Frontend dan backend akan dihubungkan menggunakan API.
- Kedua project akan dideploy ke Vercel.
